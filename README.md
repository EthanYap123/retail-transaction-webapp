# Retail Transaction Web Application

A full-stack web application that allows users to view and filter retail transaction data by categories and payment methods. Built as a student project during Year 1 Semester 2 at Singapore Polytechnic for the Fundamentals of Programming 2 (FOP2) module.

## 🌟 Features
* **Full-Stack Architecture**: Dynamic Node.js & Express server serving transaction records from local dataset storage.
* **Modular Web Components**: High-fidelity frontend built with vanilla JavaScript custom web components (`webComponent.js`) for rendering data grids and options dynamically.
* **Interactive Filtering**: Filter transactional items and group/sort based on payment type and categories.

## 🛠️ Technologies
* **Frontend**: HTML5, CSS3, Vanilla JavaScript (Custom Web Components)
* **Backend**: Node.js, Express
